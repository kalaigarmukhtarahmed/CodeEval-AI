# Sample Evaluation Test Project

Sample repository for testing and evaluating CodeEval AI's end-to-end analysis, security scanning, architecture check, performance detection, and pytest execution.

## Features Included
- Python REST/service module structure
- Security anti-patterns (hardcoded secret, string formatting in query)
- Performance anti-patterns (query in loop, file open in loop, sorting in loop)
- Circular dependency between `main.py` and `services.py`
- Full `pytest` test suite with 6 passing tests
